# hr_project

### Requirements
- vueJS 3.x
- TailwindCSS (tailwind ui : https://tailwindui.com/components)
- Flowbite (https://flowbite.com/docs/getting-started/vue/)
- Vite (https://vitejs.dev/guide/)
- ICON (https://v1.heroicons.com) > find then uses 
    e.g. import { XIcon, RefreshIcon, {IconName}Icon } from "@heroicons/vue/solid"; "solid or outline"
    
## Project setup
```
npm ci
```
