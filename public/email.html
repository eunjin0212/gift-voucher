Cara Penukaran Voucher

  1. Klik Url Link untuk di redeem.
  2. Klik redeem, lalu akan muncul code voucher..
  3. Copy code voucher, lalu buka aplikasi Gojek untuk proses penukaran..
  4. Masuk ke dalam halaman ‘Profil saya di pojok kanan atas homescreen Gojek..
  5. Pilih menu “Masukkan Kode Voucher” lalu paste kode voucher yang sudah anda copy dari link dalam email, tekan “Verifikasi Kode mu”..
  6. Voucher anda sudah dapat digunakan. Untuk kembali mengecek apakah voucher sudah ter-redeem, anda bisa cek kembali di menu “voucher saya” di dalam menu Profil saya.
